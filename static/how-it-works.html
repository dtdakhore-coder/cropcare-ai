HOW IT WORKS

From a photo to crop guidance.

A clear four-stage workflow designed around validation, prediction and understandable advice.

01
UPLOAD

Capture or choose a crop image

The user uploads a JPEG, PNG or WEBP image. The UI shows a preview before analysis begins.

02
GATEKEEPER

Check whether the image is suitable

A validation layer helps stop unrelated images from being forced into one of the disease classes.

Plant / crop image? YES → continue NO → reject
03
38-CLASS MODEL

Run the trained image classifier

The validated image is preprocessed and passed to the trained model. The class with the strongest supported prediction is returned with a confidence score.

04
ADVISORY

Explain the result clearly

The predicted class is mapped to crop-specific symptoms, prevention and practical next steps from the advisory knowledge base.
